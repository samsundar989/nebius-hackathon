Leakproof

An agent that fixes memory-safety defects in C/C++ code and reports a fix only when an evidence gate verifies it: the crash is gone, the program still behaves the same on a corpus, re-fuzzing with amplified inputs finds nothing new, LeakSanitizer is clean, and the tests pass. Verified fixes, or nothing. On Nebius Token Factory, Nemotron 3 Ultra plans, 3.5 Lightning patches, and 3 Super attacks every candidate on projects without tests.

Limitations

  • ARVO has no memory-leak cases; leak results come from Juliet, which is synthetic.
  • The gate proves absence of the reported crash and of new sanitizer reports on the inputs it tries. It cannot prove a fix correct for every input (for example, a stack buffer sized from input length).
  • Calibration false rejects come from known limits: a strict rule for patches that remove a free, and crashes the original bug used to mask.
  • Reviewer notes are an LLM review shown for context only: they flag verified and rejected candidates at about the same rate, so they are not evidence and never change a verdict.
  • Nebius Sandboxes runs the Juliet suite with the gate offline; ARVO images do not import there yet, so ARVO runs on local Docker.
