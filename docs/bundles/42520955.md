## Root cause (planner)

config->default_listener points into the config->listeners array, but when config__add_listener() reallocates the array (line 149), the pointer is not updated. The realloc frees the old array, leaving config->default_listener dangling. Later, config__read_file_core() at line 2098 dereferences this dangling pointer (config->default_listener->port), causing the use-after-free.
